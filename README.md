# React Native Clinical App

This is the frontend mobile application for the Clinical Patient Management System.

## 📋 Prerequisites

Before running this mobile app, **you must have the backend server running**.

1.  Clone the backend repository:
    [https://github.com/Magduri/MAPD712_react_native_Backend](https://github.com/Magduri/MAPD712_react_native_Backend)
2.  Follow the backend README instructions to start the server (usually running on port 3000).

## 🚀 Getting Started

Once the backend is live, follow these steps to run the mobile app:

### 1. Install Dependencies
Open your terminal in this project folder and install the required packages:

```bash
npm install
```
### 2. Run the Application

Start the Expo development server:

```Bash
npx expo start
```
For iOS: Press i to open in the iOS Simulator.

For Android: Press a to open in the Android Emulator.

For Physical Device: Scan the QR code using the Expo Go app.

### 🧪 Running Tests

This project uses Jest and React Native Testing Library for integration testing.

To run the test suite:

```Bash
npm test
```
